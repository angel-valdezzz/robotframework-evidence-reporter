# Visual examples

These are real standalone HTML files generated by the package's report engine. Data and images are fictitious and explicitly identified as demonstrations. The interface defaults to English; business labels retain the demo's Spanish content.

## PDF example

[View sample PDF](demo/passed.pdf){ .md-button .md-button--primary target="_blank" rel="noopener" }

The PDF is generated by Evidence Reporter's own export engine from the same passing case as the HTML demo. It contains fictitious data, milestones, screenshots and evidence statuses. The link opens the static PDF in a new tab; your browser may display or download it according to its settings.

Select an image to enlarge it. Download an HTML and open it offline. The passing demo contains direct evidence, two milestones and a capture warning. The skipped demo represents a case skipped before its body: status and reason, without captures. Skipping during a flow retains earlier evidence; see [skipped cases](guide.md#skipped-cases-skip).

`examples/browser.robot` captures a real fictitious local application and is verified with Chrome under Xvfb in CI. Its reports are stored as artifacts, separate from the illustrative images in these demos.

Demos include Summary (Resumen), Steps (Pasos), Logs, light/dark controls and four evidence statuses. Evidence FAIL does not change test status. SKIP applies only to execution and appears amber.

## Try the controls

1. Open **Pasos**: direct evidence starts collapsed, and both milestones start expanded.
2. Collapse all milestones and expand them again. Direct evidence keeps its own state.
3. Expand direct evidence and switch between **Evidencias** and **Logs del bloque**.
4. Inspect **Cliente registrado** and **Cuentas consultadas**, which have distinct images and messages.
5. Switch to dark mode or enlarge a screenshot.

!!! info "Illustrative data"
    Demo balances and accounts are fictitious. Reports use the same engine as the library.
