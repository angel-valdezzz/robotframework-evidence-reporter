# Referencia de keywords

[Consultar keywords en Libdoc](reference/keywords.html){ .md-button .md-button--primary }

La referencia oficial se genera desde la librería Python con **Libdoc de Robot Framework**. Incluye configuración de importación, firmas, argumentos, valores predeterminados, retornos, errores y ejemplos de las siete keywords.

Usa la búsqueda de Libdoc para localizar una keyword y su enlace directo para compartirla. La [guía de uso](guide.md) explica cómo combinar las keywords en un caso; esta página no mantiene un catálogo manual duplicado.
